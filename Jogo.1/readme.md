# ✊ 📄 ✂️ Jokenpô (Pedra, Papel e Tesoura) em Python

Um clássico jogo de Pedra, Papel e Tesoura desenvolvido em Python para rodar diretamente no terminal. Este projeto faz parte dos meus estudos práticos de lógica de programação, focando em validação de dados, controle de fluxo e manipulação de strings.

---

## 🚀 Funcionalidades

* **Sistema de Placar Melhor de 3:** O jogo continua em loop até que o jogador ou o computador alcance 2 vitórias.
* **Validação Robusta de Entrada:** O programa valida se a escolha do usuário é válida (`pedra`, `papel` ou `tesoura`), rejeitando entradas incorretas e pedindo novamente.
* **Case-Insensitive:** Utiliza `.lower()` para garantir que o programa aceite entradas independentemente de letras maiúsculas ou minúsculas (ex: "Pedra", "PEDRA" ou "pedra").
* **Jogadas Aleatórias:** O computador utiliza a biblioteca nativa `random` para fazer suas escolhas de forma imprevisível.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* Biblioteca nativa `random`
